01

专案背景Background

代币公开发行最常见的痛点，是抢跑与狙击：机器人通过监控内存池，在开盘瞬间以极低价格抢先成交， 随后迅速抛售，形成对普通参与者的价格剥削。传统的「先到先得」认购模式，反而放大了这种优势。

本案采用 Meteora Alpha Vault 的 Pro-Rata（按比例分配）模式，结合 Launch Pool 的 DLMM 流动性池， 实现公平、透明的预启动认购机制。存款窗口内所有资金进入同一资金池，窗口关闭后由合约在保护窗口内 统一执行买入，从根本上消除「谁先存谁价低」的可能。

Alpha Vault 运行在 Solana 主网，并非独立的 AMM，而是一个账户制分配层—— 它连接到一个 Meteora Launch Pool，使用该池子执行实际买入。所有分配、退款与释放均由链上合约自动执行， 无需人工干预，也无需自定义开发。

04

统一币价机制Pro-Rata Pricing

本方案采用 Alpha Vault 的 Pro-Rata（按比例分配）模式，核心机制是 先统一归集，再统一买入，最后按比例分配。

1
统一归集
存款窗口开启后，A / B / C / D 白名单成员将 USDC 存入同一个 Alpha Vault。 所有资金进入统一资金池，由 vault 合约统一管理，任何单笔存款都无法改变整体买入价格。
2
统一买入
存款窗口关闭后，Alpha Vault 在 Launch Pool 的预激活保护窗口内， 用全部可用资金以同一个价格、统一执行买入。 买入价格由池子参数决定，对所有参与者完全相同。
3
按比例分配
买入完成后，系统记录本次买入获得的代币总量。每个人的分配公式为：
你的代币 = （你的存款 ÷ 总存款）× 本次买入的代币总量

这意味着：无论你存 1,000 U 还是 100 U，你获得的代币都是按同一个平均成本计算的。 存款多的人拿到的代币多，但单价完全相同。

超额认购处理：Pro-Rata 模式原生支持超额认购。如果总存款超过预设的买入上限， 超出部分按比例退还。最终所有人的实际买入均价仍然一致。

技术执行说明Technical Implementation

本方案的技术实现依托 Meteora Alpha Vault 的原生功能，无需自定义开发， 所有参数均通过标准指令配置。

白名单实现 Whitelist
采用 Authority-Managed Escrow 模式（PermissionWithAuthority）。 Vault 创建者（authority）为每个白名单钱包创建独立的 escrow 账户， 并分别设定各组的 max_cap（最大存入额度）。 该模式操作简单，适合精选白名单名单。
统一币价 Pro-Rata
Vault 以 Pro-Rata 模式初始化（initialize_vault_with_prorata_config）， 所有参与者按存款比例分配代币。max_buying_cap 参数限定 vault 在池子中可交换的 quote 总量，超出部分自动退还。
释放机制 Vesting
Vesting 通过 start_vesting_point 与 end_vesting_point 参数配置。 Cliff 0 天表示无额外锁仓；首次 claim 为公开交易时间，随后 60 天线性解锁。 主网锁定 / vesting 时长上限约一年，60 天远低于该限制。
前置条件 Prerequisite
需先创建 Meteora Launch Pool（DLMM 类型），且该池子必须将 Alpha Vault 地址记录为白名单预激活买家。

安全说明Security & Risk Control

参与 Alpha Vault 的资金安全是最高优先级。本方案依托 Solana 主网上成熟的基础设施， 从智能合约、资金托管、机制设计、用户操作四个维度提供全方位的安全保障。

合约代码审计 Smart Contract
Alpha Vault 由 Meteora 官方团队开发，并非项目方自行编写的合约。 其底层代码经历了多家顶级安全机构（如 OtterSec、Sec3 等）的严格审计， 合约完全开源，所有逻辑在链上公开透明，杜绝了暗箱操作与后门代码的风险。
资金非托管 Custody
用户的认购资金（USDC）直接存入链上的 Vault 智能合约， 项目方无法提前触碰或挪用这笔资金。存款、买入、退款、释放，每一个步骤均由合约根据预设条件自动执行。
退款保障机制 Refund
若发生超额认购（存款总额超出硬顶），或者由于极端行情导致未能完成买入， 未成功买入的 USDC 将原路自动退还至用户的存款地址，不存在资金被冻结或卡住的风险。
防狙击保护 Anti-Sniping
机制内置了预激活保护窗口（Pre-activation Window）。 在 TGE 正式对外公开交易之前，Alpha Vault 会在这个保护窗口内完成统一买入。 这有效防止了机器人通过监控内存池在开盘瞬间抢跑或进行三明治攻击。
账户隔离 Escrow
系统为每一个白名单地址创建独立的隔离账户（Escrow）并设定专属额度。 任何人的存入行为互不干扰，合约层面的余额独立计算，防止了跨账户的攻击风险。
操作安全防范 Operation
参与过程中，用户仅需授权 USDC 的转账权限，切勿向任何人泄露私钥或助记词。 务必认准本页面公布的官方入口（caishendao.world），谨防钓鱼网站。

风险提示：虽然协议层与机制层具有极高的安全性，但数字资产市场价格波动剧烈。 智能合约仍存在极低概率的未知漏洞风险，请确保仅使用您能承受损失的资金参与。
